# Real-estate-project


Capstone Project Portfolio: "Project ResiValue BI"

Title: Engineering an Enterprise Power BI Ecosystem for Predictive CapEx Allocation and Asset Value Maximization in Residential Real Estate
Academic/Professional Track: Business Intelligence, Data Journalism, & Corporate Performance Management

🎯 1. Proposed Problem Statement

"Real estate asset management firms managing large, distributed residential portfolios frequently struggle with inefficient Capital Expenditure (CapEx) deployment, resulting in reactive maintenance cycles and stagnant portfolio equity. Without a central business intelligence ecosystem, corporate leadership lacks cross-filtering visibility to tie physical property degradation directly to financial underperformance.
This project addresses the lack of unified descriptive and predictive analytics frameworks in property management, which currently leads to siloed reporting, long asset vacancy periods, and predictable portfolio valuation leakage of 12–18% annually due to uncoordinated property lifecycle tracking."

📋 2. Full Project Blueprint & BI Methodology


🏢 Project Objectives

• Unify Siloed Data Streams: Ingest, clean, and model separate structural, financial, and operational datasets into a high-performance star schema.
• Democratize Strategic Decisions: Design an intuitive, multi-page executive report utilizing native semantic search and conditional alerting to accelerate management decision velocity.
• Surface Actionable ROI: Build advanced calculations that dynamically isolate lagging properties from top-tier revenue generators across regions.

🏗️ Data Architecture & Star Schema Design

To simulate the problem-solving process without seeing the raw source database, the data engine is built on an optimized, high-performance Star Schema structure designed for efficient relational modeling:
                  [ Dim_Property_Master ]
                             │
                             ▼
  [ Dim_Calendar ] ──> [ Fact_CapEx_Ledger ] <── [ Dim_Geography ]
                             ▲
                             │
                   [ Dim_Property_Status ]
• Fact_CapEx_Ledger: Contains transactional data including Property ID, date key, operational cost, maintenance tickets, and post-renovation appraisal values.
• Dim_Property_Master: Contains slowly changing dimensions (SCD Type 2) including physical attributes, bedroom configurations, floor numbers, and unique traits (e.g., waterfront status).
• Dim_Property_Status: Contains categorical dimensions including renovation flags, physical health tiers, and compliance scoring.
• Dim_Geography: Contains geographic hierarchies (Region ➔ State ➔ City ➔ Zip Code) for precise geospatial drill-downs.

🎛️ 3. DAX Measure Engine & Data Expression Architecture

In place of a standard timeline, this project is governed by a robust framework of customized Data Analysis Expressions (DAX) that drive the backend calculations.
• Portfolio Health Index (PHI) Engine
Calculates a normalized health score by factoring in property age and the frequency of historical maintenance incidents.dax
Property Health Index = 
VAR AssetAge = YEAR(TODAY()) - SELECTEDVALUE(Dim_Property_Master[ConstructionYear])
VAR TicketCount = COUNTROWS(RELATEDTABLE(Fact_CapEx_Ledger))
RETURN 
MAX(0, MIN(100, 100 - (AssetAge * 1.5) - (TicketCount * 2.0)))
Use code with caution.
• Dynamic Capital Expenditure ROI
Calculates the immediate valuation return yielded from capital modernizations across specific asset classes.dax
Renovation ROI % = 
DIVIDE(
    [Total Appraised Value] - [Total Historical Cost], 
    [Total Renovation Spend], 
    0
)
Use code with caution.
• Value Leakage Tracking
Quantifies the unrealized financial equity trapped within assets currently categorized as unrenovated or in sub-optimal physical condition.dax
Portfolio Value Leakage = 
SUMX(
    FILTER(Dim_Property_Status, Dim_Property_Status[Condition] = "Poor" || Dim_Property_Status[IsRenovated] = FALSE),
    [Total Appraised Value] * 0.15
)
Use code with caution.

💡 4. Dashboard Visual Layout & Strategic Insights

• The Executive Executive Summary (Page 1): Focuses on high-level high-yield KPIs (Total Portfolio Value, Overall Portfolio Health, Net Renovation ROI). Employs conditional formatting visual alerts that highlight structural maintenance risks in high-demand configurations (like 3 and 4-bedroom profiles).
• Geospatial & Clustering Analysis (Page 2): Integrates native map visual extensions to isolate geographic value variance. This allows users to cross-filter and discover localized premium trends—such as the exact value lift generated by unique environmental factors like waterfront assets.
• Prescriptive CapEx Planning (Page 3): An operational worksheet page that uses Power BI "What-If" parameter sliders to let managers dynamically adjust corporate budget constraints and immediately see which specific asset segments should receive immediate modernizations.
